# Nitro.jl — agent instructions

**Nitro.jl** is an SPA/API-first web framework for Julia: Django-style routing and sessions, Go-style
per-request threading, Express-style response builders and middleware, Spring-style typed binding.

- **Contributing to Nitro itself** — the design lineage, the rules that apply to every change, the
  hard-stop index, the area rule files, the architecture map and the verification commands:
  @CONTRIBUTING.md
- **Writing an application that *uses* Nitro** — read
  [`.github/skills/nitro-usage/SKILL.md`](.github/skills/nitro-usage/SKILL.md) (`/nitro-usage` in
  Claude Code); [`add-route`](.github/skills/add-route/SKILL.md) and
  [`deploy-checklist`](.github/skills/deploy-checklist/SKILL.md) ship beside it.
